# SMART YIELD PROPERTY identity

The mark combines architectural S and Y forms, an ascending path, and a brass cornerstone to connect the business name with property and long-term growth.

- Primary color: forest green `#123e31`.
- Accent: muted brass `#b89a61`.
- Reversed artwork: warm ivory `#f7f5ed` with the brass accent retained.
- Header master: `public/images/smart-yield-logo.svg`.
- Footer master: `public/images/smart-yield-logo-light.svg`.
- Browser icon: `public/favicon.svg`.
- Generated direction reference: `public/images/brand/smart-yield-concept.png`; the website uses the clean SVG production artwork.

Preserve the SVG proportions and transparent background. Use the primary version on light surfaces and the reversed version on dark surfaces. Avoid stretching, adding shadows, or recoloring the brass accent. Keep at least the height of the small PROPERTY lettering as clear space around the mark.
